# 🛠️ C Utilities

A collection of small, fast C programs I use for day-to-day tasks and automation.

## Utilities Included

| Tool                               | Description                                    | How to Compile / Run                              |
| :--------------------------------- | :--------------------------------------------- | :------------------------------------------------ |
| **[text_counter](./text_counter)** | Counts words, lines, and characters in a file. | `gcc text_counter/main.c -o counter && ./counter` |
| **[quick_calc](./quick_calc)**     | A quick command-line calculator.               | `gcc quick_calc/main.c -o calc && ./calc`         |

## Requirements

- A standard C compiler (`gcc`, `clang`, etc.)
- Make (optional, if using a Makefile)
